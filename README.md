# RoughHoop

RoughHoop is a real-time, event-driven data processing engine for autonomous decision-making on a scalable service platform.

With RoughHoop, you get a lightweight tool that stays out of your way.

**What you get**

- RoughHoop is a real-time, event-driven
- data processing engine for autonomous
- decision-making on a scalable service

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughHoop.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

RoughHoop is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
